# Taller de Estimadores — Estadística Matemática

Este repositorio contiene el desarrollo del **Taller de Estimadores** correspondiente al tercer corte de la asignatura de **Estadística Matemática**.

## Contenido del taller

El taller aborda los siguientes temas:

- **Definición de estimadores**: comprensión del concepto de estimación puntual.
- **Propiedades deseables de los estimadores**:
  - Insesgadez
  - Consistencia
  - Eficiencia
- **Aplicación de distintos métodos de estimación**:
  - Método de momentos
  - Método de máxima verosimilitud (MLE)
- **Análisis y comparación de distintos estimadores** usando ejemplos numéricos y simulaciones en R.

## Archivos

- `Taller Estimadores(Corte 3).Rmd`: archivo fuente en RMarkdown con el desarrollo completo del taller.
- `Taller-Estimadores-Corte-3-.html`: versión renderizada del documento en formato HTML.
- Carpeta `images/`: contiene los recursos gráficos utilizados en el taller.
